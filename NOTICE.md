# Notice

This repository contains independently written automation and receiver-wrapper
source only.

It intentionally excludes:

- Samsung APKs and firmware libraries
- Decompiled or disassembled vendor code
- Device certificates and HDCP credentials
- Pairing tokens, Wi-Fi credentials, MAC addresses, device serials, and local
  network addresses
- Captured protected media

Protocol documentation records behavior observed on devices owned and
authorized by the operator. Users must supply their own compatible hardware
and firmware.
